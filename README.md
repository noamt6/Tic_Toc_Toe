Tic-Tac-Toe (Python & Turtle GUI) 
A modular Tic-Tac-Toe game built with Python, featuring a graphical user interface and strategic AI. This project demonstrates clean code principles, state management, and data persistence.

Key Features
Multiple Game Modes: Play Player vs. Player, Player vs. Random AI, or challenge a Strategic AI.

Interactive GUI: Fully functional interface built with the turtle library, supporting both Mouse and Keyboard inputs.

Save & Load: Uses the pickle library to save the current game state and resume it later.

Game History: Tracks and displays results of previous matches in a dedicated history file.

Smart AI: A rule-based AI that prioritizes winning moves, blocking opponents, and controlling the center.

Project Structure
main.py: The entry point that initializes and connects the logic with the interface.

game_board.py: Handles game rules, win/draw detection, and data saving.

interface.py: Manages the visual rendering and user interactions.

ai_player.py: Contains the logic for random and strategic computer moves.
